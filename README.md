# DULO

> **Open Spreadsheet Engine Specification**

DULO is an open, implementation-independent specification defining how a modern spreadsheet engine should behave.

Unlike spreadsheet applications, DULO does **not** define a graphical interface. Instead, it defines the engine responsible for workbook management, worksheets, formulas, calculations, storage, extensibility, AI integration, security, and conformance.

The goal of DULO is to allow anyone to build a spreadsheet engine that behaves consistently while remaining portable, deterministic, extensible, and future-proof.

---

## Features

- 📖 Complete spreadsheet engine specification
- 📑 Workbook and worksheet model
- 🧮 Formula language specification
- ⚡ Deterministic calculation engine
- 💾 Storage and serialization architecture
- 📊 Charts and visualization model
- 🔌 Extension and plugin system
- 🤖 AI integration interface
- 🔒 Security model
- ✅ Conformance requirements
- 📚 Comprehensive appendices

## Philosophy

DULO defines **what** a spreadsheet engine should do.

It does **not** define **how** it must be implemented.

This allows implementations in:

- Rust
- C
- C++
- Go
- Java
- Python
- JavaScript
- .NET
- Any other language

---

## Conformance

An implementation may claim DULO compatibility only if it follows the requirements defined in the specification.

The official conformance requirements are documented in Chapter 14 and Appendix C.
